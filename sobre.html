SOBRE O PROJETO

Conheça o PixelVerse

O PixelVerse é um site criado para apresentar informações sobre Games em Pixel Art.

NOSSO OBJETIVO

Por que criamos este site?

O objetivo do projeto é mostrar como os jogos em Pixel Art conseguem criar personagens, cenários e histórias utilizando um estilo visual simples, criativo e marcante.

🎮 Tema

O tema escolhido foi Games em Pixel Art, explorando o universo dos jogos retrô.

💻 Tecnologias

O projeto utiliza HTML5 e CSS3, além de JavaScript como recurso adicional.

🌐 Publicação

O projeto será armazenado no GitHub e publicado na Internet utilizando o Vercel.

Por que Pixel Art?

Escolhemos esse tema porque a Pixel Art faz parte da história dos videogames e continua sendo utilizada em muitos jogos modernos.
